    What is reinforcement learning?

    The formal idea

    Reinforcement learning is a computational approach to goal-directed learning from interaction. The learner is the agent. The external system it interacts with is the environment. The agent observes the present situation, selects an action, receives a numerical reward, and then observes the next situation.

    Reinforcement learning is learning what to do, meaning how to map situations to actions, so as to maximize a numerical reward signal. The learner is not told which action is correct. It must discover useful actions by trying them.

    At time step t the agent observes a state St and selects an action At. The environment then produces a reward Rt+1 and a new state St+1. The objective is to maximize cumulative reward over time, not just the next reward, so RL is about choosing actions that shape future situations and future rewards.

    Step through one interaction

    The agent–environment view

    The boundary is drawn by what the learner can directly control. The agent controls its actions. The environment includes everything that responds to them, including state transitions and the reward mechanism. A learning agent must be able to sense the state, take actions that affect it, and have a goal expressed through reward.

    Trial and error

    The agent must test actions to learn their consequences.

    Delayed reward

    An action affects the next state and, through it, many later rewards. This makes RL a framework for sequential decisions under uncertainty.

    How RL differs from supervised and unsupervised learning

    Compare the three paradigms

    In supervised learning, examples of correct behaviour are supplied. In RL they usually are not: the agent may know an outcome was good or bad without knowing which action it should have chosen instead. This creates the need for exploration and credit assignment. In unsupervised learning the aim is to find hidden structure, while in RL it is to learn behaviour that maximizes reward.

    Spot the paradigm

      Important characteristics of RL

      Reward-based feedback

      RL uses rewards rather than labels. The feedback evaluates the action taken but does not specify the best possible action.

      Sequential decision-making

      The present action can change the next state, and the next state changes which actions are available later. A good decision must consider future consequences.

      Delayed consequences

      Rewards may arrive long after the action that caused them. A move that looks weak now may set up a strong future position, and a tempting immediate reward may lead to a poor long-term return.

      Exploration and exploitation

      The agent must use what it knows, but also try less-known actions to find out whether better ones exist. If it only exploits, it may settle too early for a suboptimal action. If it only explores, it fails to benefit from what it has learned. Good RL balances both.

      Uncertainty

      The agent usually has incomplete knowledge of the environment. Outcomes may be stochastic, so the same action may not always lead to the same result.

      Elements of reinforcement learning

      Beyond the agent and environment, an RL system has four main subelements: a policy, a reward signal, a value function and, optionally, a model of the environment.

      Six building blocks

      Reward vs value

      Reward tells you what is good immediately. Value tells you what is good in the long run. A state may give low reward but have high value because it leads to better states, and the reverse is also possible. That is why RL decisions rest mostly on value judgments.

      Illustrative numbers

      State A, reward0.1
      State A, value0.8
      State B, reward0.7
      State B, value0.2

      State A sets up a strong future position. State B offers a tempting immediate benefit. A value-based agent prefers A.

      Model-based and model-free methods

      Model-based

      Uses a model of the environment for planning or prediction. Planning means considering possible future situations before experiencing them.

      Model-free

      Learns directly from experience without an explicit model of the environment.

      Applications of reinforcement learning

      RL suits problems where decisions are sequential, outcomes are uncertain, and actions influence future opportunities.

      Game playingTic-tac-toe, chess, Go, Atari, strategy games
      RoboticsBalance, walking, navigation, grasping, manipulation
      Autonomous drivingLane decisions, speed control, planning under uncertainty
      Industrial controlRefinery control, energy management, process optimization
      OperationsScheduling, inventory control, traffic signal control, resource allocation
      Digital systemsRecommendation, personalization, advertising, web services
      Healthcare and educationAdaptive interventions, tutoring, treatment planning, with safety constraints
      FinanceSequential investment, bidding, risk-sensitive decisions

      The pattern is the same everywhere: act now, observe what happens, and improve future decisions. An action cannot be judged only by its immediate effect. It must be judged by the later states and rewards it helps produce.

      Review of key terms

      A toy example: tic-tac-toe

      States, actions and rewards

      Tic-tac-toe has states, actions, rewards, delayed consequences and a clear goal. A board position is a state and a legal move is an action. In the simple textbook setup a win gives reward 1, while a loss or draw gives 0.

      The value-function approach gives every board position a number that estimates the probability of winning from it. Winning states start at 1, lost or drawn terminal states at 0, and all other states at a neutral 0.5. During play the agent usually picks the move leading to the highest-valued next state (a greedy move) and occasionally picks another move to explore.

      The temporal-difference rule

      Let St be the state before a greedy move and St+1 the state after it. With step size α:

      V(St) ← V(St) + α [ V(St+1) − V(St) ]

      The bracket is the temporal-difference part. The earlier state’s value moves part of the way toward the later state’s value.

      Try the update

      The update never replaces the old estimate fully. A small α gives slow, stable learning, and a larger α gives faster but more sensitive learning. A step size that shrinks over time lets estimates settle against a fixed opponent, while one that does not vanish lets the learner keep adapting if the opponent changes slowly.

      Review questions

      Exam-style questions

      Try to answer each one first, then open it to check the key points.

      1. Define RL using the agent–environment framework. Explain state, action, reward and cumulative reward.
      • The agent learns from interaction with an environment to achieve a goal.
      • At step t it observes St, selects At, and receives Rt+1 and St+1.
      • State is the current situation, action is the decision, and reward is the numerical feedback.
      • The objective is cumulative reward over time, not only the next reward.
      2. Compare RL with supervised and unsupervised learning. Distinguish instructive from evaluative feedback.
      • Supervised: labeled examples from a teacher, so feedback is instructive (it states the correct output).
      • Unsupervised: no labels and no reward, so the aim is to find structure.
      • RL: a scalar reward from actions, so feedback is evaluative (it judges the action but does not name the best one).
      • This creates the need for exploration and credit assignment.
      3. Explain the four main elements. Why is the value function especially important?
      • Policy: the behaviour rule from states to actions.
      • Reward signal: immediate feedback defining the goal.
      • Value function: long-term desirability from expected future reward.
      • Model (optional): predicts next state and reward, and supports planning.
      • Value matters because reward is immediate, but good decisions depend on long-run consequences.
      4. Discuss the exploration–exploitation trade-off.
      • Exploitation uses current knowledge. Exploration tries less-known actions.
      • Only exploiting can lock in a suboptimal action too early.
      • Only exploring wastes what has been learned.
      • Good RL balances the two.
      5. In tic-tac-toe, explain value initialization, move selection and the TD update.
      • Initialization: winning states 1, lost or drawn terminal states 0, all others 0.5.
      • Selection: mostly greedy toward the highest-valued next state, with occasional exploratory moves.
      • Update: V(St) ← V(St) + α[V(St+1) − V(St)] after a greedy move.
      • The earlier value moves part of the way toward the later one, with α setting how far.

      Summary and reading

      Points to remember

      • RL is a third major learning paradigm, different from supervised and unsupervised learning.
      • The agent learns from interaction, not from a fixed dataset of correct answers.
      • The reward signal defines the goal, but the value function supports long-term decisions.
      • Exploration is necessary because the agent must discover useful actions through experience.
      • The temporal-difference rule adjusts an earlier estimate using a later one, so learning can happen step by step during interaction.
